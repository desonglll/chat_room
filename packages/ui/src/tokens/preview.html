Every pane below is the same DOM, cloned from one <template>. The only difference between the left pane and the right pane is the value of data-tg-theme on the wrapper. Accent and wallpaper are likewise attributes on the wrapper. No markup, class or rule in this page mentions a theme, an accent or a colour value — that is the switchability claim, and this page is the proof of it. If a swatch reads unset, a semantic token named in the frozen list is missing from a theme file.
