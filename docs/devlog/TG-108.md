## Frozen interface

- New semantic tokens (`semantic.css`): `--tg-ease-linear` and one name per audited interaction —
  `--tg-motion-sidebar`, `--tg-motion-chat-switch`, `--tg-motion-message-enter`,
  `--tg-motion-press`, `--tg-motion-panel`, `--tg-motion-modal`. All map onto the TG-009 springs.
- `ContextMenu` exposes `data-tg-holding` while a touch long press is being timed.
- `MessageRow` takes optional `sentAt`; `isFreshMessage(sentAt, mountedAt)` / `FRESH_MESSAGE_MS`.

## Decisions

- Audit result: every component duration was already a token; the gaps were bare `linear`
  keywords, ease-curves on modal/sheet/popover/mobile push, and three interactions with no motion
  at all (desktop sidebar collapse, message arrival, long-press feedback).
- Springs everywhere a thing moves: sidebar collapse animates `grid-template-columns` with the
  smooth (critically damped) spring, disabled while the resizer is dragged; mobile list↔chat push
  and panels use the springs; modal/sheet/popover appear on the standard spring instead of the
  overshoot bezier.
- Message entrance only for messages younger than 3 s at row mount, decided once (history pages,
  virtualised remounts of old rows and re-renders never replay it). Fill-mode `backwards` so no
  transform lingers to trap fixed-position descendants.
- Long press: bubble scales to 0.96 while the 500 ms hold is timed (Telegram iOS); under reduced
  motion it dims instead of scaling.
- Reduced motion keeps relying on TG-009's token collapse (durations → 1 ms, springs → linear);
  the new motion tokens inherit it automatically.
- Gate: `packages/web/test/motionDiscipline.test.ts` scans web + ui CSS (tokens excepted): no
  literal duration / cubic-bezier / easing keyword in any transition/animation declaration, and
  any keyframe that moves must run on a collapsing duration or sit in a file with its own
  reduced-motion block.
