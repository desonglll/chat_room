## Decisions

- 2026-10-01 Guard hard-coded CJK with a source-scanning test (`englishUi.test.ts`) instead of only eyeballing screenshots,
  because the static sweep is exhaustive and re-runs in `bun test`; screenshots only show what the walk reached.
  The regex includes full-width punctuation (`：，「」（）`), which a plain 一-鿿 grep misses — that is where all the
  real leftovers were.
- 2026-10-01 Lines owned by other agents stay as named PENDING allowlist entries rather than being fixed here
  (ownership rule); a staleness assertion fails when an entry no longer matches, so the list can only shrink.
- 2026-10-01 Punctuation helpers live in core (`speaker` etc.) rather than per-feature keys, because ten call sites in six
  features need the same three shapes; importing a function (not just a key) also guarantees core's catalog is
  registered — core is `sideEffects: false`, so `t.ts` is otherwise droppable.
- 2026-10-01 Per-account reset follows the existing sticker/GIF library pattern (`authStore.subscribe` on token change)
  instead of a central sign-out hook, so each store owns its own lifecycle and no shared hotspot is touched.
- 2026-10-01 The account-switch E2E step signs out and in through the UI without `page.goto`, because a reload resets
  every module store: the first version (with `goto`) passed on the unfixed build. Verified the rewritten step fails on
  the unfixed build (`alice's folder tab, wallpaper shown to bob`) and passes on the fix.
- 2026-10-01 Bob seeing «很久以前上线» for an online friend who hides last seen is NOT changed: `accounts/privacy/last_seen.rs`
  documents it as deliberate (obscured tiers ignore today's activity so they cannot leak an online moment; a brand-new
  account therefore reads «long ago»). The E2E asserts "an obscured tier, never 在线 or a time" instead.
- 2026-10-01 The walkthrough ran the API from a server binary built from this worktree (no Rust change) and the UI from
  this worktree's `vite preview` (proxy config `packages/web/vite.tg1204.config.mjs`, untracked, deleted at the end), per
  the brief's embedded-bundle hazard. An early run used the lead's stale binary (pre-TG-903, 405 on
  `/api/friends/statuses`); none of the reported results come from it.
