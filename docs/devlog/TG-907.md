## Frozen interface

- none on the server. The TUI consumes: `/api/friends`, `/api/friends/statuses`,
  `/api/friend-requests` (GET incoming, POST, PATCH), `/api/users/search`, `/api/direct-chats`,
  `/api/chats/:id/pins[/:message_id]`, `/api/messages/forward`, the `pins_changed` frame and
  `last_message.media_kind`.

## Decisions

- 2026-10-01 Survey: the TUI already had chats, send/reply/edit/recall/react, upload/download,
  search, notifications, favorites (and AI, which stays as it was — AI is off server-side). Unknown
  frames were already ignored safely. Gaps vs Web: media previews, contacts / friend requests,
  pinned messages, forwarding — those are what this task adds.
- 2026-10-01 Contacts is a new tab placed before AI so the existing tab numbers (1–4) do not move.
  Rows: incoming requests first (`a` accept, `x` decline), then friends online-first by most recent
  last-seen; Enter opens/creates the private chat and connects; `n` adds by @username (exact match
  from `/api/users/search`, accepting a pending incoming request the same way the server does).
- 2026-10-01 Pins: loaded on connect and on every `pins_changed` frame; shown in the messages pane
  title (`· 📌 newest (+N)`) and as `· pinned` on the row; `P` pins/unpins the selected message.
- 2026-10-01 Forward: `F` asks for a chat title (exact, then prefix, case-insensitive); the status
  line reports success, a voice-privacy refusal, or the server's skip reason.
- 2026-10-01 Previews: `[Voice message]`, `[Poll] Lunch?` … from `media_kind`; a live message's
  attachment is classified by MIME.
- 2026-10-01 Kept every touched file under the size gate by moving `View` out of `model.rs` and
  putting the new behaviour in new files (`social.rs`, `dispatch_social.rs`, `update_social.rs`,
  `render_social.rs`, `client_api_social.rs`).
