## Decisions

- 2026-10-01 tsconfig split: `src/` is checked with `types: []` and `lib: ES2022 + WebWorker` —
  the Fetch API surface every host provides, without `window`/`document`/`localStorage`. Seeding
  a file that touches all three makes `tsc` fail on each (verified, then removed). Tests and the
  Bun-only benchmark (`bun:jsc`, `Bun.*`) are checked by `tsconfig.test.json`; `bun run typecheck`
  runs both.
- 2026-10-01 `createSocket` throwing synchronously now counts as a failed attempt: status
  `offline` (or `idle` after close) and a scheduled retry, instead of an exception out of
  `connect()` and a socket stuck on `connecting`.
- 2026-10-01 Catch-up filtering compares instants, not RFC 3339 strings (`.500Z` sorts before `Z`
  lexically). `chatListStore.isNewer` already used `Date.parse` — left as is.
