## Frozen interface

- `GET /api/users/me/wallpapers` → `Wallpaper[]`; `PUT /api/users/me/wallpapers/{scope}`
  `{kind: preset|color|gradient, preset?, colors?, blur?, dim?}`; `POST …/{scope}/image`
  (multipart `file`, `blur`, `dim`; ≤ 8 MiB; PNG/JPEG/GIF/WebP/AVIF by magic bytes);
  `GET …/{scope}/image` (owner only); `DELETE …/{scope}`. `scope` = `global` or a readable chat id.
- Settings (per device): `theme: light|dark|system|scheduled`, `accent` (8 ids), `nightFrom`,
  `nightTo`. Core: `ACCENTS`, `resolveThemeAt`, `isNightAt`, `exportTheme`/`importTheme`
  (`{format: "tg-theme", version: 1, …}`), `createWallpapersApi`, `effectiveWallpaper`.

## Decisions

- Theme and accent are attributes on `<html>` (`data-tg-theme`, `data-tg-accent`) driving the
  TG-009 token layers; no component reads a theme. Added Telegram's red (#d33213) and gray
  (#6d839e) accents with the same derivations as the existing six → eight.
- Scheduled night mode re-evaluates every minute; a window may cross midnight.
- Wallpapers are per account on the server (global + per-chat override, chat wins). Presets are
  the 14 token presets; colours/gradients feed the same 4-point mesh via custom properties; images
  are stored like avatars and served only to their owner (fetched with the token into an object
  URL). Blur and dim (0–80 %) are CSS on the wallpaper layer; dim is a scrim over the wallpaper
  only, so bubbles keep full contrast.
- Scroll performance: the wallpaper is one absolutely positioned layer behind the chat pane
  (`contain: strict`, own compositor layer), never inside the message scroller and never
  `background-attachment: fixed`; a structural test pins this. A browser frame-time benchmark is
  not part of this repository's test tooling (see residual risk).
- Custom theme export/import is a small JSON document (theme mode, accent, night window).
