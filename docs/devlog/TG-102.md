## Frozen interface

**Chat-list row (`packages/web/src/features/chatList/ChatListRow.tsx`)** — plain props:

```ts
interface ChatListRowProps {
  model: ChatRowModel            // chatRowModel.ts: chatId, chatType, title, avatar*, preview,
                                 // time, unreadCount, muted, pinned, outgoing ('sent'|'read'|null), showsPresence
  href: string; active: boolean; collapsed?: boolean
  isOnline?: boolean             // TG-107 seam; undefined = unknown (no dot); private chats only
  typingText?: string | null     // TG-107 seam; replaces the preview line while set
  onOpen?: (chatId, event) => void
}
```

**Presence seam** — `chatRowPresence.ts::useChatRowPresence(conversation, currentUserId) → { isOnline, typingText }`.
Today it derives from `presenceStore` (only populated for the open chat). TG-107 replaces this
hook's body with its own hooks; nothing else changes.

**Read-state seam** — `RowContext.isReadByPeer?(chatId, messageId)` in `chatRowModel.ts`. No
server data exists yet, so own last messages show a single tick ("已发送").

**`chatListStore` (core)** — existing `chats` slice and actions unchanged. Added:
`conversations: ConversationSummary[]`, `setConversations`, `applyAccountMessage(event, activeChatId)`,
`applyUnreadCounts(states)`, `applyLatestMessage(chatId, message)`; pure exports
`sortConversations`, `isConversationMuted(conversation, nowMs)`, `conversationChatType`; wire
mirrors `ConversationSummary`, `ConversationPreferences`, `ConversationLastMessage`,
`ConversationPeer`, `NotificationLevel`, `AccountMessageEvent`, `AccountChatState`.
`setUnreadCount` / `removeChat` / `applyChatUpdated` now also update `conversations`.

**Shell** — `WorkspaceShell` sets `--tg-shell-sidebar-width` and `data-mobile-view="list|chat"`,
`data-sidebar-collapsed`, `data-info-open`. Sidebar layout persisted under storage key
`tg.sidebar.v1` (`{width, collapsed}`), mirrored into `uiStore.sidebarWidth/sidebarCollapsed`.
`MobileBackButton` (shell) is exported for a chat header to render inline.

**Wire consumed (read-only, no server change)** — `GET /api/conversations`,
`/ws/account` (`{token}` auth frame; `new_message`, `unread_counts`).

## Decisions

- 2026-10-01 Sidebar rows come from `GET /api/conversations`, not `GET /api/chats`, because only
  the former carries pin/archive/mute preferences, the last-message preview and the private-chat
  peer. `/api/chats` is still loaded too (header/info pane read `selectChatById`). No server field
  was added: `src/conversations/**` and `src/chats/**` are TG-208's active paths.
- 2026-10-01 Wire types for the conversation list live in `chatListStore.ts` (beside their only
  store) and the fetch in `chatListController.ts`, instead of a new `packages/core/src/api/conversations.ts`,
  because `packages/core/src/api/**` is not in this card's paths. Move them when TG-208 settles the list contract.
- 2026-10-01 Live updates: the account socket (`/ws/account`, polled server-side every 750 ms)
  for other members' messages + unread snapshot, and a `messageStore` subscription
  (`timelineMirror.ts`) for own sends/recalls in open chats — the account socket never echoes own
  messages. On reconnect or an unknown chat id, the list resyncs over REST.
- 2026-10-01 Sort is a pure function over the whole list (pinned first in the main list only,
  newest activity by instant, id tie-break, archived last) — the server order is not trusted
  after live updates.
- 2026-10-01 Time format: `HH:mm` today (and ≤1 day of future clock skew), `周X` for 1–6 days
  ago, `M月D日` this year, `YYYY/M/D` otherwise — Telegram's rule, Chinese copy.
- 2026-10-01 Media kind is inferred from the attachment file extension because the list summary
  carries no MIME type; unknown extensions are "file" and show the file name.
- 2026-10-01 Draft marker uses `composerStore.drafts` only (the TG-008 cloud draft is loaded when
  a chat is opened). Fetching every chat's draft on load would be N requests; the right fix is a
  `draft` field on the list summary (see Residual risk).
- 2026-10-01 Sidebar: 260–480 px, default 360 (the `--tg-column-width` token), drag below 180 px
  collapses to an 80 px avatar column, keeping the last width for un-collapse. Persist on drag end,
  not per pointer move. Keyboard: separator role, ←/→ ±16 px, Enter toggles collapse, Home resets.
- 2026-10-01 Mobile (<600 px): both columns stay mounted at 100% width and switch by
  `transform` only (no reflow → no layout jump, measured: widths 390/390 before and after); the
  hidden column is `inert`. Reduced motion removes the transition.
- 2026-10-01 Mobile back: the shell renders a floating `MobileBackButton` over the chat header
  and pads `.tg-chat__header` on mobile, because `ChatPane.tsx` is TG-101's file. Integration can
  move the button into the header instead (patch list).
- 2026-10-01 Info pane: grid column only from 1276 px; below that an overlay on the right (full
  width on mobile). InfoPane.tsx itself is untouched (TG-106).
- 2026-10-01 Glyphs (pin, mute, ticks, media, archive, hamburger) are inline SVGs in
  `chatListIcons.tsx`: the shared sprite has none of them, and `web/public` is not ours.

## Residual risk

- `/api/conversations` is being unified by TG-208; if its shape changes, only `chatRowModel.ts`,
  `chatListFilters.ts` and the wire mirror in `chatListStore.ts` need to follow.
- Double tick never shows today (no server data); drafts only show for chats opened this session.
- Unread for the open chat is forced to 0 in the row; the server-side count is only reset when the
  chat pane sends a read cursor (TG-101). Seeded data showed a WS send does not advance the sender's read cursor, so
  a chat whose last message is yours can still carry an unread badge from earlier messages.
- Account socket is a 750 ms server poll; a burst of messages arrives batched. Reconnect uses the
  shared backoff curve and resyncs over REST.
- Mobile: when going back, the outlet swaps to the empty state immediately, so the chat content
  disappears while the pane slides out (the geometry does not jump).
