## Work

- **`web/` deleted** (the frozen Vue client). The eight files `src/web.rs` embeds by fixed path
  moved to `packages/web/public/` (vite copies them into the build); `build.rs` no longer
  stages anything from `web/` (it only writes the retiring service worker until TG-601ships a
  real one); Dockerfile, CI (old Vue steps removed), `.gitignore` and the size baseline updated.
- **`/api/rooms/*` alias removed**: the second mount, the dialect middleware/extractor
  (`chats/compat.rs`) and the deprecated OpenAPI twins are gone; `/api-docs/openapi.json` now
  serves `ApiDoc` directly (`api_doc::openapi_json`). `ChatCompatView` (the `name` duplicate) is
  gone too — `/api/conversations` returns a plain `Chat` as `group`. `name` is still accepted on
  input. `grep -rn "/api/rooms" src/ packages/` → nothing.
- **ratatui CLI** on `/api/chats/*` (`title`, filters private chats out of the chat directory as
  the alias used to); **stress tool** on `/api/chats`; **desktop** filters private chats from the
  directory the same way (TG-603 moved it to `/api/chats`).
- Comments that cited deleted Vue sources were reworded.
- Tests: `chat_api_alias_test.rs` deleted; alias cases dropped from the read-authorization and
  draft tests; `private_chat_path_test` now asserts `/api/rooms` answers 404.
- Docs: `docs/client-capability-matrix.md` rewritten; README architecture diagram and
  verification steps updated.
