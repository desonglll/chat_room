### Storage (migration `20270101000002_add_video_notes`, SQLite + PostgreSQL)

- A video note is an attachment message with `messages.media_kind = 'video_note'` plus one
  `video_notes` row: `(message_id PK → messages ON DELETE CASCADE, duration_ms INTEGER > 0,
  thumbnail BLOB/BYTEA NULL (a small JPEG, ≤ 16 KiB), duration_source 'container'|'client',
  created_at)`.
- `video_note_listens(message_id → video_notes ON DELETE CASCADE, user_id → users, listened_at)`,
  PK `(message_id, user_id)`. The sender never has a row for their own message.

### Wire

- `VideoNote { duration_ms: u32, thumbnail: string | null (base64 JPEG), listened: bool }` —
  Rust `src/attachments/video_note/model.rs`, TS `packages/core/src/types/message.ts`.
- `StoredMessage.video_note?` / `broadcast.video_note?` — omitted unless the message is a video
  note whose attachment the viewer can see. `media_kind: "video_note"` rides along.
- `listened` is per viewer, exactly like `VoiceNote.listened` (TG-401).
- The first view by someone else emits the existing **`voice_listened`** frame
  (`{message_id, user_id, sender_id}`), delivered only to the listener's and sender's own
  connections. The frame means "media content played" (Telegram's `readMessageContents`
  covers voice and round video alike); clients key it by message id.

### HTTP (`src/attachments/video_note/handlers.rs`, OpenAPI-registered)

| Method | Path | Body | Answers |
| --- | --- | --- | --- |
| POST | `/api/chats/:id/video_note` | multipart: `file` (WebM or MP4 with a video track), `duration_ms` (recorder measurement), `thumbnail?` (JPEG ≤ 16 KiB), `reply_to?` | 201 `StoredMessage` with `video_note` |
| POST | `/api/messages/:message_id/video_note/listened` | — | 204 (idempotent; sender's own = no-op) |

Errors (JSON `{error}`): 400 `invalid_duration` (0 or > 60 s + 1 s framing grace) /
`missing_duration` / `missing_file` / `invalid_thumbnail`; 401; 403 `forbidden` or
`voice_messages_restricted` (TG-505: Telegram's "voice messages" privacy rule covers video
messages too); 404 (never distinguished); 413 `too_large` (16 MiB, or the deployment limit if
lower); 415 `unsupported_video` (not WebM/MP4 by magic bytes, or no video track).

Stored MIME/name come from the sniffed container: `video/webm` `video_note.webm`,
`video/mp4` `video_note.mp4`.

### Client

- `packages/web/src/features/videoNote/videoNoteApi.ts`: `sendVideoNote(fetch, {chatId, token,
  video, fileName, durationMs, thumbnail?, replyTo?})`, `markVideoNoteListened(client, token, id)`.
- `features/videoNote` exports `RecordModeButton` (the composer's mic/camera button — replaces
  `VoiceRecordButton` in the composer, same props), `VideoNoteContent` (bubble); `register.ts`
  registers kind `video_note` at priority 41, frame `bare`, meta `overlay`.
- Types in `@tg/core`: `VideoNote`; `StoredMessage.video_note?`; `BroadcastFrame.video_note?`;
  `storedMessageToBroadcast` carries it.
