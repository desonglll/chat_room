## Offline scope (the definition the card asks for)

- **Readable offline**: the app shell and every hashed asset fetched once; the chat list
  (`/api/conversations`, `/api/chats`, chat descriptors) and every message page opened while
  online (network-first, cache on failure); media already viewed (attachments, avatars,
  stickers) within the user's TG-509 limits (`cacheLimitMb`, `cacheRetentionDays`), evicted by
  retention first, then oldest-first by size.
- **Drafts offline**: the composer keeps the draft locally; it syncs to the cloud draft when the
  connection returns. **Sending needs a connection** (no offline send queue).
- **Not cached**: writes, sockets, search, link previews, map tiles, other origins.
- **Sign-out** tells the worker to delete the API and media caches, so nothing of the account
  stays readable offline.
