## Keyboard (acceptance path without a mouse)

1. **Sign in** — the login form is native inputs + submit: Tab between fields, Enter submits.
2. **Switch chats** — `Alt+↑/↓` walks the chat list exactly as shown (folder, search, archive);
   `Ctrl/⌘+K` (or `/` outside a text field) focuses chat search; chat rows are links (Tab/Enter);
   `Ctrl/⌘+Shift+1…9` picks a folder (1 = 全部).
3. **Send** — Enter in the composer (Shift+Enter per the send setting).
4. **Reply** — `Ctrl/⌘+↑` in the composer replies to the newest message, again for older ones;
   `Ctrl/⌘+↓` moves newer and clears past the newest (Telegram Desktop behaviour); Esc cancels.
5. **Open settings** — `Ctrl/⌘+,`; Esc closes it (existing).

Telegram Desktop's own keys that the browser reserves (Ctrl+Tab, Ctrl+1…9, Ctrl+F) were
deliberately not taken. The map is one pure function (`features/shortcuts/keymap.ts`, 3 tests)
installed once in `WorkspaceShell`; the search field advertises `aria-keyshortcuts`.

## Focus

Dialogs, sheets, menus and popovers already trap and restore focus (`@tg/ui`
`useFocusTrap`/`useRestoreFocus`, roving focus in menus) — audited, unchanged.

## Contrast

`packages/ui/src/test/contrast.test.ts` measures every text/background pair from the token files.
Strict pairs (body, secondary, link, danger, bubble text) must reach 4.5:1 in both themes; two
**text** tokens were adjusted to get there (day danger text 4.27 → 4.69, night link 4.31 → 5.19,
hue kept, fills untouched). Per the lead's ruling, accent-fill text and decorated meta keep
Telegram's values; the register with measured ratios and reasons is
`docs/tg/contrast-deviations.md` and is pinned by the test.
