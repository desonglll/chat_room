## Frozen interface

- `GET /api/public-usernames/:username/check` → `{ username, available, reason? }`.
- `PUT /api/chats/:id/username` `{ username | null }` — `chat.info`; 400/409 bodies are
  `{ "error": <reason> }` (`too_short`, `too_long`, `invalid_characters`,
  `must_start_with_letter`, `invalid_underscores`, `reserved`, `taken`, `password_protected`,
  `not_supported`). A group becomes a supergroup.
- `GET /api/public/:username` → `PublicChatPreview` (title, description, avatar emoji, type,
  member count, is_member, requires_approval; `chat_id` ONLY for members).
- `POST /api/public/:username/join` → the ordinary join (`request_join`): 200 joined, 202 request.
- `GET /api/chats/discover?q=` — handle prefix (leading `@` ignored) or title substring,
  case-insensitive; exact handle first.
- Web: route `/public/:username`, «公开链接» editor in the admin panel, «全局搜索» under the chat
  list search.

## Decisions

- 2026-10-01 Telegram's handle rules (5–32 of a–z 0–9 _, starts with a letter, no trailing or
  doubled underscore) plus a reserved list covering this product's routes. Handles are stored
  lowercase so the existing partial unique index (`chats_username_active_idx`) enforces
  case-insensitive uniqueness; a racing duplicate that slips past the pre-check is mapped from
  the index's unique violation to 409.
- 2026-10-01 One namespace with user logins (Telegram's `t.me/<name>` is shared), so a user's
  login cannot be taken as a chat handle.
- 2026-10-01 "Do not leak the internal id": the preview omits `chat_id` for non-members; joining
  goes through the handle and calls the existing `request_join` handler directly, so bans, chat
  locks, approval and the join policy stay in one place. A chat with a join password cannot be
  public (and is never resolvable).
- 2026-10-01 The route is `/public/:username`, not `/@name` or `/<name>`: React Router cannot
  match a partial segment, and a bare `/<name>` would shadow the app's own routes.
- 2026-10-01 `access_hash` is not exposed anywhere new; the handle is the public key.
