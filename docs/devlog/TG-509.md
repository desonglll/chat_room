## Decisions

- 2026-10-01 Telegram's automatic-download matrix: per network (Wi-Fi / mobile data / roaming),
  photos / videos / files, with a size cap for videos and files. The network comes from the
  Network Information API where it exists; Save-Data is treated as roaming (the strictest), and an
  unknown connection as Wi-Fi. A refused medium shows «点击下载 · size» until tapped.
- 2026-10-01 Usage is what the browser reports (`navigator.storage.estimate`) plus the Cache
  Storage partitions; «清除缓存» deletes the Cache Storage only. Media on screen are live DOM
  elements, so clearing never breaks what is being viewed (the card's requirement).
- 2026-10-01 Per-chat cache cleanup is not offered: the app keeps no per-chat cache today (the
  service worker is still the self-unregistering stub from TG-003). The ceiling and retention are
  stored now and are the contract for TG-601's offline cache.
