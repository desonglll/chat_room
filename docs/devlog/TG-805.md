## Decisions

- 2026-10-01 Audited before adding: TG-108/TG-411 already deliver message enter (others rise,
  own message flies in), reaction pop + ring, big-emoji, popover/menu scale-in from the anchor
  corner (`Popover.css` per-placement `transform-origin`), dialog/sheet in/out, info + settings panel
  push, typing dots, unread badge pop/out (`Badge.css` `--tg-ease-badge-in/out`), scroll-to-bottom FAB
  show/hide, composer bar/popup pop, skeleton rows while the list loads, all with reduced-motion
  folding in `tokens/semantic.css`. Re-doing those would only churn.
- 2026-10-01 Added the four that were missing:
  1. **Chat-list reorder** — FLIP (`flipReorder.ts`): a chat that jumps to the top on a new message
     glides there and the rows it passed slide down; WAAPI on `transform` only, 250 ms,
     `cubic-bezier(0.25,0.1,0.25,1)`. A folder / custom folder / query / collapse change is a new
     list and does not animate. Reduced motion: skipped.
  2. **Mic ↔ send morph** — the new glyph turns 45° and grows from 0.4 (200 ms, decelerate) on every
     switch (both buttons share `.tg-compose__send`); reduced motion: fade only.
  3. **Chat switch** — the message list is keyed per chat, so its mount fades and rises 12 px
     (200 ms); phones skip it (the pane already slides), reduced motion fades only.
  4. **Row press** — `:active` uses `--tg-surface-active` with the press duration.
- 2026-10-01 The FLIP duration/easing are JS constants (WAAPI cannot read a CSS custom property
  as a duration); they match `--tg-duration-exit`-scale values and the card's ease.
