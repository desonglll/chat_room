## Gap survey (server has it, TUI did not) — written before coding

Already present in the TUI (TG-907 survey + code read): reply (`R`), edit (`e`), recall (`x`),
add reaction (`+`), global search tab, chat pin/archive/mute (`p`/`a`/`m`/`t`), typing line,
read receipts, forward (`F`), message pin (`P`), poll vote (`V`), folders (`o`).

Missing, in the order implemented:

1. Reply context is never shown on a message (the frame's `reply_to` preview, quote, cross-chat
   source are dropped) — you can reply but cannot see what a message replies to.
2. Quote reply (`reply_quote`) — no way to quote part of a message.
3. Reactions are not shown on messages, and a reaction can only be added, never removed.
4. In-chat search (`/api/chats/:id/messages/search`) — only the global tab exists.
5. Silent send (`silent`).
6. Scheduled messages: schedule, list, send now, cancel.
7. Join by invite link (`/api/invite-links/:token/join`, incl. the approval-queue answer).
8. Typing actions: every action renders as "is typing" (recording voice, choosing sticker …).

Deliberately not in scope: cross-chat reply *sending* (needs a two-chat picker; receiving and
showing it is covered), message effects, translation (both are visual/Web-only), stickers/GIF
sending (TG-1103 already ruled out).

## Decisions

<!--
  Every non-obvious choice, with the reason. The reason is the part that
  survives; "switched to X" without "because Y" is worthless to the next agent
  and will be re-litigated.
-->

- 2026-10-01 Silent/scheduled/search/join are composer **slash commands** (`/silent`, `/schedule
  <when> [/silent] <text>`, `/scheduled`, `/search`, `/join`) rather than new modifier keys,
  because Alt/Ctrl+Enter are not reliably distinguishable across terminals and the commands are
  self-describing in the composer title. Only known commands are intercepted: an unknown `/word`
  is sent as text, `//text` sends `/text`; a misused command keeps the draft and shows its usage.
- 2026-10-01 `/schedule` times: `30m`/`2h`/`1d`, `HH:MM` (today, tomorrow once passed), or
  `YYYY-MM-DD HH:MM`, all local time; past times are refused client-side (the server would 400).
- 2026-10-01 Quote reply = `Q` opens a prompt pre-filled with the message; the user trims it to the
  part to quote. Checked client-side to be a substring and ≤ 1024 UTF-16 units (the server's
  `MAX_QUOTE_UTF16`), so a quote is never silently degraded to a plain reply by the server.
- 2026-10-01 Reaction removal = `-👍` in the existing `+` prompt instead of a separate key: the TUI
  does not know its own user id, so it cannot tell whether a tap should toggle. Counts come from
  the frame's `reactions` and `reaction_changed.user_id` (deduplicated per user).
- 2026-10-01 Typing: `ChatEvent::Typing` now carries the whole line (`bob is choosing a sticker`)
  instead of the bare name, so the render path does not need to know about actions.
- 2026-10-01 Paths outside `src/bin/client_tui/**` (necessary; the wire decode and API client live
  one level up): `client.rs` (3 mod lines), `client_chat_protocol.rs` (+ its tests),
  `client_chat.rs` (one test literal), new `client_chat_extras.rs`, `client_api_messages.rs`,
  `client_messages_e2e_tests.rs`. No server, web or shared-hotspot change.
- 2026-10-01 Deliberately not done: sending cross-chat replies (needs a two-chat picker; received
  ones render as `↳ bob in Team: …`), message effects and translation (visual / Web-only).

## Residual risk

<!-- What a reviewer should distrust. Empty is a valid answer only if you looked. -->

- The interactive terminal itself is not driven (needs a TTY); key flows are tested through
  `App::handle_key` and drawing through ratatui's `TestBackend`, the wire through the real server.
- `/schedule HH:MM` and dates use the machine's local timezone; DST gaps resolve to the earliest
  valid instant (`from_local_datetime(..).earliest()`), an ambiguous/missing time is a usage error.
- Reaction counts start from the history frame and follow `reaction_changed`; a server older than
  `user_id` on that frame leaves counts unchanged rather than guessing.
- Slash commands shadow messages that start with `/silent`, `/schedule`, `/scheduled`, `/search`,
  `/join` — `//` escapes them.
