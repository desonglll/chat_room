## Frozen interface

- `GET /api/chats/:id/slow-mode` → `{ seconds, wait_seconds, exempt }` (members only).
- `PUT /api/chats/:id/slow-mode` `{ seconds }` — one of 0, 10, 30, 60, 300, 900, 3600; needs
  `members.ban`; a group becomes a supergroup (TG-201 `apply_chat_capabilities`). 400 / 403 / 409.
- `TopicError::SlowMode(wait)` from `resolve_post_topic` → 429 on the topic REST mapping; other
  send paths map it through their existing catch-all (403/400), and the WS path drops the frame
  with a warning, as it does for a closed topic.

## Decisions

- 2026-10-01 Enforced inside `resolve_post_topic`, the post gate every live send path already
  calls (WS text, attachments incl. chunked, stickers, GIFs, polls, voice, video notes, albums,
  forwards, favorite shares) — one check instead of eleven, and new send paths inherit it.
  Scheduling and scheduled delivery use `resolve_scheduled_post_topic` (no throttle): scheduling
  writes no message, and a scheduled message was accepted when it was scheduled.
- 2026-10-01 The last-post time is `MAX(created_at)` of the sender's messages in the chat,
  recalled ones included (delete-and-resend must not skip the wait). New index
  `messages (room_id, sender_id, created_at)` (migration `20261101000008`) keeps it an index
  lookup; the card said "no migration" because the column existed — the index is new.
- 2026-10-01 Owners and administrators are exempt (Telegram). Changing the interval needs
  `members.ban` (Telegram shows it under Permissions to admins who restrict members).
- 2026-10-01 Racing sends inside the same instant can both pass: a rate limit, not an invariant.
- 2026-10-01 Client: `useSlowMode` reads the server state when the chat opens, then restarts the
  countdown locally from the viewer's own acknowledged messages; the composer's send is disabled
  and a «慢速模式已开启 · 还需等待 m:ss» strip shows above it. The member-restriction UI the card
  mentions already exists from TG-201 (`chatAdmin` restricted editor); the interval picker is added
  to the group permissions page.
