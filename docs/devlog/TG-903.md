## Frozen interface

- `GET /api/friends/statuses` → `[{ user_id, status }]` (the `auth_ok.statuses` shape), one per
  accepted friend, computed with the same TG-505 `last_seen` reciprocity as the WS snapshot
  (`ViewerContext::exact_visible`); online = connected to any chat. 401 without a session.
- `SocialApi.friendStatuses()`.

## Decisions

- 2026-10-01 Presence comes from a dedicated endpoint, polled every 60 s and on friend-count change,
  rather than adding `status` to `SocialUser` (shared with search, requests and blocks, where a
  status would be a privacy question of its own).
- 2026-10-01 Reused `ViewerContext` (made `pub(super)`) instead of re-implementing the rule: the
  friends' tiers are filled in after building the context with no room.
- 2026-10-01 List: online first, then newest exact last-seen, then the privacy buckets, then name;
  in-place filter over shown name, remark, display name and @username. Row click opens the private
  chat; message / remark / remove / block live in the row's right-click / long-press menu and ⋮.
- 2026-10-01 **Found while verifying**: picking «备注» from the row menu closed the menu, whose focus
  restoration blurred the new field and its `onBlur` cancelled the edit — the remark could never be
  typed. Fixed (no cancel-on-blur; Escape cancels; focus is taken after the menu has closed).
- 2026-10-01 **Found while verifying**: at phone width every non-chat page (联系人, 通知, 收藏夹,
  管理后台, …) was unreachable — the shell showed the main pane only for `/chat/*`. The shell now
  shows the main pane for every route but `/`, and those pages got the mobile back button.
