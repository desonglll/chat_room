## Frozen interface

- `GET/POST /api/users/me/folders`, `PUT /api/users/me/folders/order {folder_ids}`,
  `PUT/DELETE /api/users/me/folders/{id}`. Body/response `ChatFolder {id,title,emoji,
  include_types[private|groups|channels],include_chat_ids,exclude_chat_ids,exclude_muted,
  exclude_read,exclude_archived}`; list in display order.
- Limits: ≤10 folders, title 1–12 chars, ≥1 type or chat, ≤200 chat ids per list; naming a chat
  the caller cannot read is 404; reorder must name exactly the caller's folders.
- Core: `inFolder` / `folderConversations` / `folderUnread` / `MAX_CHAT_FOLDERS`,
  `createFoldersApi`, `settingsStore.folderLayout: 'top'|'left'`.

## Decisions

- Folder membership is evaluated client-side from the chat list (the server stores only the
  rules), so unread badges and the list always agree and no per-message fan-out is needed.
- Read-time authorization: chats the owner has left drop out of `include/exclude_chat_ids` on read.
- Explicit exclude beats explicit include; exclusion flags (muted/read/archived) apply even to
  explicitly included chats (Telegram behaviour). A folder shows archived chats unless it
  excludes them.
- A timed mute counts as muted only until `muted_until`.
- Layout: tabs above the list (default) or a left rail, chosen in 设置 › 聊天文件夹; stored per
  browser in settingsStore.
