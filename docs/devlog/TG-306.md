## Frozen interface

`packages/web/src/features/sticker/renderer` (import from `./index`). Everything TG-301 exported
is still exported with the same meaning. The additions are:

- `<Sticker sticker={StickerDescriptor} data? cacheKey? size=160 loop=true autoplay=true poster? label? className? onError? manager? webmSupported?>`
  is the single entry for every format.
  - `tgs` renders `<AnimatedSticker>` (TG-301), so its DOM is unchanged: there is no `data-format`.
  - `webp` renders `span.tg-sticker[data-format=webp][data-phase=loading|static|error] > img.tg-sticker__still`.
  - `webm` renders `span.tg-sticker[data-format=webm][data-phase=loading|static|live] > video.tg-sticker__video`.
    The video is muted, looped (when `loop`), `playsinline`, and uses `preload=auto`.
  - When WebM falls back, it renders `span.tg-sticker[data-format=webm][data-phase=static][data-fallback=unsupported|decode-error]`
    with `img.tg-sticker__still` (the thumbnail) or `span.tg-sticker__emoji`.
  - `label` defaults to `sticker.emoji` and `poster` defaults to `sticker.thumbnail_url`.
  - `data` holds bytes already in memory and wins over the URL.
- `StickerDescriptor` is `{ format?, mime_type?, file_url?, download_url?, thumbnail_url?, emoji?, width?, height? }`.
  It is structural, so a TG-302 catalogue `Sticker` fits as is. `download_url` wins over `file_url`.
- `stickerFromMessage(message) → StickerDescriptor | null` turns a sticker message
  (`message.sticker` plus `message.attachment.download_url`/`mime_type`) into a descriptor. It
  returns null for a message that is not a sticker, or one that was recalled and so has no
  `sticker` block.
- `wireStickerFormat(d)` reads `format`, then `mime_type`, and otherwise returns null.
  `sniffStickerFormat(bytes)` detects gzip → `tgs`, `RIFF….WEBP` → `webp`, EBML → `webm`, and a
  JSON object (BOM and whitespace allowed) → `tgs`. `stickerUrl(d)`.
- `webmStickerSupported()`, `detectWebmStickerSupport({canPlayType, userAgent})`, and
  `setWebmStickerSupport(bool|null)` (an override for tests and the fixture page).
- `StickerRenderManager.attachMotion({ element, key, loop, autoplay, onPlayback(playing, reducedMotion) }) → { replay(), ended(), destroy() }`
  is new. `ManagerStats` gains `motionViews` and `playingMotionViews`.
- The TG-301 optional props of `AnimatedSticker` now also accept an explicit `undefined`
  (`exactOptionalPropertyTypes`). This only widens the type.

## Decisions

- 2026-10-01 WebM videos register with the **same manager** as TGS, through `attachMotion`
  (`motionViews.ts`). That makes one call to `admitPlayback` decide both formats. The results:
  one concurrency cap, the same viewport observer (100 px margin), the same hidden-tab and
  reduced-motion signals, and a playing sticker keeps its slot. A second, parallel "video
  manager" would have needed a shared cap anyway. `stickerManager.ts` grew by 13 lines
  (314 → 327).
- 2026-10-01 Each `<video>` is **its own group in the cap**, even when two copies play the same
  file. Every element runs its own decoder, so two copies cost twice. TGS copies, by contrast,
  share a single render.
- 2026-10-01 Under reduced motion the manager tells the view `(playing=false, reducedMotion=true)`,
  and the view seeks to 0, which shows the first frame. An off-screen or over-cap pause holds
  the current frame instead, so the sticker does not visibly jump. `preload=auto` is used
  because stickers are at most 256 KiB and a paused video needs decoded data to show its first
  frame. Safari does not paint a frame on `metadata` alone.
- 2026-10-01 **The WebM capability rule** is: `canPlayType('video/webm; codecs="vp9"') !== ''`
  AND the browser is not Apple WebKit (Safari, or any iOS browser). There is no feature query
  for alpha, and `canPlayType` only reports whether VP9 WebM plays, not whether it keeps
  transparency. Safari versions that do play VP9 have shown the alpha plane as opaque black.
  This is the same trade Telegram's web clients make, and it is conservative: a new Safari that
  does render alpha still gets the thumbnail. Relaxing the rule is a one-line change in
  `webmSupport.ts`.
- 2026-10-01 **The fallback is the thumbnail, else the emoji**, and it does not draw a
  "first frame on canvas". The browsers that hit the fallback either cannot decode the video at
  all or would lose its alpha, so a canvas frame would be a black square. TG-302 has no
  thumbnail field yet. `thumbnail_url` is read if it ever appears, and `poster` can pass one in
  today. A `<video>` that errors at runtime takes the same fallback, with
  `data-fallback=decode-error`.
- 2026-10-01 The wire `format` wins over `mime_type`, and magic bytes are read only when both
  are missing or unknown. A trusted wire field costs no fetch. When the format is undeclared,
  the sniff fetches the URL once and renders from those bytes (as a blob URL, or as TGS
  `data`), so the file is not fetched a second time.
- 2026-10-01 The WebP path has no manager registration. TG-302 rejects animated WebP, so there
  is nothing to pause or cap. The browser's `<img>` decode is enough.
- 2026-10-01 Fixture media is generated in the browser at load time
  (`bench/mixedMedia.ts`): WebP comes from `canvas.toBlob('image/webp')` and WebM from
  `MediaRecorder` over a transparent canvas (VP9). No binary is checked in, and no copyrighted
  sticker is used. The pixels are written as `ImageData`, because the token-discipline gate
  forbids colour literals in `packages/web/src`.

## Residual risk

- The Apple WebKit rule is by user agent. A Safari that does render VP9 alpha still gets the
  fallback, and a browser that spoofs a non-Safari user agent on WebKit would get a black
  background. The real Safari path was never run on real Safari; it was forced in Chromium.
- WebM stickers without a thumbnail fall back to the emoji glyph. That is honest, but it is a
  weaker look than Telegram's server-generated thumbnails. The server should add a thumbnail
  (a WebP first frame) so the fallback has one.
- `preload=auto` loads every mounted WebM in full (at most 256 KiB each). Lists are virtualized,
  but a panel with many WebM stickers downloads them all. Telegram does the same; revisit this
  if TG-303's panel mounts hundreds of stickers.
- Paused off-screen videos keep their decoder until unmount. TGS units are released after 10 s,
  but video elements are not. A long virtualized list unmounts them anyway.
