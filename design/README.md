# Echo Gate 品牌与界面设计规范

版本：1.0  
日期：2026-08-18  
适用范围：Web、PWA、桌面端包装、社交分享图和产品文档

## 1. 品牌核心

Echo Gate 的识别物不是纸飞机，也不是两个聊天气泡，而是一扇正在打开的“回声门”。门表示房间、边界和加入关系；门板下方的折角同时像一句正在说出的话；暖黄色圆点表示在线的人。

- 品牌符号：回声门 Echo Gate
- 吉祥物：敲敲 Knocki
- 品牌性格：清楚、有人情味、可靠、轻快但不幼稚
- 产品主张：进入房间，认真说话
- 避免：蓝色纸飞机、双气泡轮廓、社交软件常见的满屏蓝紫渐变

“敲敲”是回声门的拟人化。它是一位小型房间守门员：绿色拱门是身体，浅色门洞是脸，珊瑚色门板像一条会回应的尾巴，黄色门铃代表在线状态。

## 3. 配色系统

主色“信号绿”承担品牌、主按钮、当前房间和自己的消息；“珊瑚红”用于提醒、未读重点及危险操作；“门铃黄”只做小面积在线与温度提示；“深墨色”用于文字和深色背景。

| 名称 | 色值 | 主要用途 |
| --- | --- | --- |
| Signal Jade 700 | `#087F6B` | 浅色模式主按钮、品牌色 |
| Signal Jade 800 | `#066456` | 主按钮悬停、强调文字 |
| Signal Jade 100 | `#DDF4EC` | 当前房间、自己的消息 |
| Knock Coral 500 | `#FF6B57` | 未读重点、回复尾巴、品牌辅色 |
| Knock Coral 700 | `#B9362B` | 危险按钮与错误文字 |
| Doorbell Sun 500 | `#F4B942` | 在线、邀请、等待状态 |
| Ink 950 | `#172321` | 主文字、深色品牌底 |
| Paper 50 | `#F7FAF9` | 应用背景 |
| Mist 200 | `#DCE6E2` | 分隔线、控件边框 |

颜色比例建议为：中性色 72%、信号绿 18%、珊瑚红 7%、门铃黄 3%。不要把珊瑚红或黄色铺成大面积背景。

## 4. 标志规则

- 标准背景优先使用 `Paper 50`、白色或 `Ink 950`。
- 图标四周最小留白等于黄色门铃圆点的直径。
- 标准符号最小尺寸 20 px；低于 32 px 时不要附带文字。
- 横向组合最小宽度 136 px；中文副标仅用于宽度不小于 220 px 的场景。
- 不要旋转、拉伸、改成单线稿、添加投影或重新分配三种品牌色。
- 应用图标已经包含安全区，不要再套白色圆角方块。

## 5. 吉祥物规则

敲敲用于空状态、首次进入、连接中、离线和轻量成功反馈，不替代关键文字或状态图标。

- 标准姿势：迎接或空状态，建议 120–240 px。
- 打招呼：新用户、加入成功。
- 输入中：房间空白等待、实时输入提示。
- 离线：网络断开、房间暂不可用。
- 不给敲敲穿品牌联名服装，不改变脸部比例，不在身体上放文字。
- 小于 64 px 时改用 `echo-gate.svg`，不要继续缩小吉祥物。

## 6. 图标语言

自有图标使用 24 × 24 网格、1.8 px 描边、圆端点和圆连接。房间、加入、消息和发送图标继承“门框 + 折角”的品牌母形；搜索、设置等通用图标保持熟悉的操作隐喻。

- 默认尺寸：导航 20 px、按钮 18 px、行内状态 16 px。
- 图标按钮最小触控区：40 × 40 px；移动端 44 × 44 px。
- 仅图标按钮必须提供 `aria-label` 和悬停提示。
- 激活图标使用信号绿；危险操作使用珊瑚红；禁用态只降低文字/描边对比度，不降低触控区。
- `icon-sprite.svg` 适合应用内批量引用；独立文件适合 favicon、文档和构建工具。

## 7. 界面应用

当前 ChatRoom 的真实功能应按以下方式映射：

| 场景 | 设计处理 |
| --- | --- |
| 房间列表 | 激活项用 Jade 100 底色和 3 px 左侧标记；未读数使用 Coral 500 |
| 私密房间 | 锁图标配 Sun 100 底色，不使用危险色 |
| 自己的消息 | Jade 100 气泡、Ink 950 文字；不要用高饱和实色大气泡 |
| 他人的消息 | 白色气泡、Mist 200 边框；头像保留暖色区分 |
| 回复引用 | 左侧 3 px Coral 500 竖线，最多显示两行 |
| 在线状态 | Sun 500 小圆点；断线使用中性灰，不用错误红持续制造压力 |
| 文件与成员 | 独立面板或对话框，不在消息气泡内嵌套卡片 |
| 危险操作 | 二次确认；按钮和说明均明确写出影响对象 |

桌面端保持“房间列表 + 对话”双栏；移动端只显示一层主任务，通过返回按钮切换。聊天工具应以扫描效率为主，不采用营销页式大标题和装饰性卡片堆叠。

## 8. 排版与形状

- 字体：`Inter`、`PingFang SC`、`Microsoft YaHei`、系统无衬线。
- 正文：14–16 px；辅助信息 12–13 px；紧凑面板标题 16–20 px。
- 字重：正文 400，标签 500，标题 650–700。
- 字距始终为 `0`，不随视口缩放字号。
- 基础圆角 6 px，气泡和弹窗 8 px，头像与状态点可用圆形。
- 不使用 16–32 px 的过度圆角卡片；不把页面区块做成漂浮卡片。

## 9. 无障碍与状态

- 正文和背景目标对比度至少 4.5:1；大字和非文字 UI 至少 3:1。
- 不仅靠颜色区分在线、未读、失败和已发送，需配合文本、图标或形状。
- 焦点环为 `2px solid #087F6B`，外偏移 2 px。
- 尊重 `prefers-reduced-motion`；连接动画不应成为唯一状态反馈。
- 发送、上传、保存都要包含 idle、hover、focus、disabled、loading、success 和 error 状态。

## 10. 前端接入

可先把 `tokens.css` 引入现有 `web/src/style.css`，再把 PrimeVue 的 primary 与 surface 色阶映射到 token。品牌标志与房间相关导航使用本套图标；纯工具型动作可继续使用现有 Lucide，但应统一描边粗细、尺寸和触控区，避免同一界面出现两种视觉重量。

这套资产为 ChatRoom 项目原创，可在本项目产品、宣传和衍生文档中使用与修改。
