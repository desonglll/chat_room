# ChatRoom icon set

这组原创图标使用 24 × 24 网格、`1.8` 描边、圆端点和圆连接。默认继承 `currentColor`。

独立文件可直接作为图片或组件输入；需要 sprite 时使用：

```html
<svg width="20" height="20" aria-hidden="true">
  <use href="/icons/icon-sprite.svg#cr-icon-rooms"></use>
</svg>
```

可用 id：`rooms`、`room-add`、`members`、`message`、`send`、`attach`、`files`、`search`、`reply`、`bell`、`settings`、`lock`、`unread`、`back`。

图标按钮需至少 40 × 40 px，移动端至少 44 × 44 px，并提供 `aria-label` 与 `title`。发送图标刻意使用“消息穿过门”的形态，不使用纸飞机。
